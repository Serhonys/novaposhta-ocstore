# Нова пошта для ocStore / OpenCart 3

Модуль доставки Нова Пошта. Поточна версія: **2.0.1**.

## Скачать

Прямая ссылка на архив установщика:

https://github.com/Serhonys/novaposhta-ocstore/releases/download/v2.0.1/novaposhta-2.0.1.ocmod.zip

Файл: `novaposhta-2.0.1.ocmod.zip`

Предыдущая версия (1.6.5):

https://github.com/Serhonys/novaposhta-ocstore/releases/download/v1.6.5/novaposhta-1.6.5.ocmod.zip

## Установка

1. Расширения → Установщик → загрузить zip.
2. Расширения → Модификации → Обновить.
3. Расширения → Расширения → Доставка → Нова Пошта → Установить → Редактировать.
4. Вставьте API-ключ (кабинет Новой Почты → Настройки → Безопасность → API).
5. В левом меню появится «Нова Пошта»: настройки на весь экран и диспетчер экспресс-накладных.

2.0.0 — новый админский экран (каталог API v2.0 и диспетчер ЕН). Это не точечный патч 1.6.5: если магазин уже работает на 1.6.x, сначала проверьте 2.0.0 на копии.
