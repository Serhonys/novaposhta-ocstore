# Нова пошта для ocStore / OpenCart 3

Модуль доставки Нова Пошта. Поточна версія: **1.6.3**.

## Скачать

Готовый архив для установщика:

https://github.com/Serhonys/novaposhta-ocstore/releases/latest

Файл: `novaposhta-1.6.3.ocmod.zip`

Каждая следующая версия будет отдельным релизом с таким же именем файла: `novaposhta-X.Y.Z.ocmod.zip`.

## Установка

1. Расширения → Установщик → загрузить zip.
2. Не удаляйте уже установленный модуль: удаление сотрёт справочник городов и накладные.
3. Откройте настройки Новой почты и обновите админку, чтобы появились пункт меню и «Мої посилки».

Номер версии виден в списке доставки, в боковом меню и на вкладке «Версії».
