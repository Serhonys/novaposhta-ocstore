Нова Пошта для ocStore 3 — версія 2.0.1
==========================================

Файл для установщика: novaposhta-2.0.1.ocmod.zip

Установка
1. Розширення → Установник → завантажте novaposhta-2.0.1.ocmod.zip
2. Розширення → Модифікації → Оновити
3. Розширення → Розширення → тип «Доставка» → Нова Пошта → Установить → Редагувати
4. Вставте API-ключ з кабінету Нової Пошти (Налаштування → Безпека → API) і натисніть «Проверить»
5. У лівому меню з’явиться пункт «Нова Пошта»: налаштування на весь екран і диспетчер експрес-накладних

Чекаут
Покупець шукає місто (searchSettlements), відділення або поштомат (getWarehouses) і вулицю для кур’єра.
Тариф береться з InternetDocument.getDocumentPrice, якщо ключ робочий. Інакше діє запасна сітка цін з прикладу модуля.
Безкоштовна доставка і накладений платіж рахуються з налаштувань.

Диспетчер
Замовлення магазину зі способом доставки Нова Пошта потрапляють у таблицю.
«Створити ЕН» викликає InternetDocument.save від контрагента-відправника з кабінету.
«Оновити статуси» викликає TrackingDocument.getStatusDocuments.

Крон трекінгу (раз на годину)
index.php?route=extension/shipping/novaposhta/cron&key=ПЕРШІ_16_СИМВОЛІВ_MD5
де md5 рахується від рядка: вашApiKey + np
